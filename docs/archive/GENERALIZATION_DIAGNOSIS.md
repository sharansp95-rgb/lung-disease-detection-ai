## FINAL DIAGNOSIS — DOMINANT CAUSE

### Evidence by Cause

#### (A) Preprocessing / crop mismatch — 3 piece(s) of evidence

- TEST 3 [xray]: `invert` drops accuracy to 10.0% — model is sensitive to preprocessing-level changes that external images may exhibit.
- TEST 3 [ct]: `histeq` drops accuracy to 45.0% — model is sensitive to preprocessing-level changes that external images may exhibit.
- TEST 6 [xray]: 4/5 failures attend to borders/corners — shortcut features from training crops, not pathology.

#### (B) Intensity / format shift — 2 piece(s) of evidence

- TEST 2 [xray]: Tensor mean Δ=0.0325, std Δ=0.1675 — intensity statistics diverge between external and training-source images.
- TEST 2 [ct]: Tensor mean Δ=0.2751, std Δ=0.0891 — intensity statistics diverge between external and training-source images.

#### (C) Source confound / distribution shift — 0 piece(s) of evidence

- No direct evidence from these tests.

### Ranking

1. **(A) Preprocessing / crop mismatch** — 3 evidence item(s)
2. **(B) Intensity / format shift** — 2 evidence item(s)
3. **(C) Source confound / distribution shift** — 0 evidence item(s)

### Plain-Language Summary

The **dominant cause is (A) preprocessing / crop mismatch**. The U-Net segmentation model was trained on the specific image style of the training datasets and produces degenerate crops on external images (border_crop or no_crop beats U-Net). Additionally, the model is sensitive to preprocessing choices (border pixels, contrast, gamma) that differ between the training pipeline and external image sources. Fix target: `seg_utils.py` crop fallback logic and external-image preprocessing normalization.

> **No model weights were changed in this diagnosis. No fix is proposed here — evidence collection only.**
